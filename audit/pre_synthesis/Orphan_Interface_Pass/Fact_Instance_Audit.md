Liveness of an instance is decided by its consumers, since an instance is never cited by name: an instance is live when a live declaration requires `Fact P` for its proposition P (binder `[Fact P]` or `Fact.out` at type P). Liveness was decided individually for groups F4 and F5; for F1 to F3 it does not affect closure, because each is discharged by a term whose content is decidable, definitional or a projection of an already constructed object.
